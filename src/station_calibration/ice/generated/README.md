# Generated Ice stubs

These files are produced by `slice2py` from:

- `_3dsc_resources/CalibrationPhenoseederIcing.ice`
- `ice/CommonPhenoseeder.ice`
- `ice/PhytoCommon.ice`
- `ice/PhytoError.ice` (placeholder include)

Do not edit them by hand. Run from the project root:

```powershell
.\.venv\Scripts\python.exe ice\generate_stubs.py
```

The generated packages use absolute imports, so `station_calibration.ice._generated`
adds this directory to `sys.path` before importing them.
